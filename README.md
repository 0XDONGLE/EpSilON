**IIS Log Analyzer** is a user-friendly desktop application built with Python and Tkinter that helps you analyze IIS (Internet Information Services) 
log files without touching the command line. Simply load your log files and get instant insights through an intuitive graphical interface.

## Features

### Core Functionality
- **📁 Drag & Drop Support** - Simply drag your log files into the application
- **🔍 Multi-file Analysis** - Analyze single or multiple log files simultaneously
- **📈 Real-time Statistics** - View metrics as soon as files are loaded

### Analysis Capabilities
- **Top Requested URLs** - Identify your most visited pages
- **IP Address Analytics** - Find top visitors and detect potential malicious activity
- **Status Code Distribution** - Visual breakdown of 2xx, 3xx, 4xx, and 5xx responses
- **Error Detection** - Automatically highlight 404 (Not Found) and 500 (Server Error)
- **Time-based Filtering** - Filter logs by date/time range
- **User Agent Analysis** - See what browsers and bots are accessing your site

### Visual Features
- **📋 Copy to Clipboard** - One-click copying of any result table
- **Progress Indicators** - Real-time progress bar for large file processing

## 🚀 Installation

### Prerequisites
- Python 3.7 or higher
- pip install pandas and tkinter
